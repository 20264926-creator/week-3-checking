🛰️ Cordillera Real-Time GPS, Parking & Hazard Map (CAR)

A real-time navigation and hazard-tracking web app for the Cordillera Administrative Region (CAR), Philippines.

✨ Key Features
📍 Live GPS & Map Location: Tracks live browser location with automatic Baguio fallback and one-click map placement.
🚶🚗🏍️🚚 Multi-Modal Routing: Turn-by-turn routing for Walking, Car, Motorcycle, and Truck modes using OSRM.
🏫 Universities & Places: Quick navigation to major CAR universities (UB, SLU, UP, UC, BSU, BCU), barangays, and custom search targets.
🅿️ Parking Directory: Vehicle-filtered parking locator showing distance and nearby spots at your destination.
⚠️ Hazard Warning System: Proximity alerts within 1 km of active hazards and a crowd-sourced road report tool.

🛰️ Map Layers: Toggle between Esri Satellite Imagery, OpenStreetMap, and World Street views without watermarks.
🚀 Quick Start

Save your project file as index.html.
Double-click index.html to launch it in any modern browser.
🛠️ Tech Stack
Frontend: Standard HTML5, CSS3, JavaScript (ES6+)
Mapping: Leaflet.js v1.9.4
Services: OSRM Routing, OpenStreetMap Nominatim Search, Esri Imagery
